# 半写实交通路口三维大屏设计规格

## 1. 目标

将 `/zhiluwujie` 从当前的霓虹赛博风场景，调整为参考图所示的“白天半写实低多边形交通仿真”风格。页面仍然是 Three.js 三维数字孪生，不替换为视频背景，也不改变现有后端数据协议、16 个场景、WebSocket 实时链路和大屏 HUD 数据功能。

第一版的成功标准是：用户一眼能识别出道路、路口、车道、斑马线、交通灯、建筑、树木、车辆和行人；场景事件能够在这些真实道路要素之间发生；画面整体克制、明亮、适合汇报展示。

## 2. 当前问题

当前 `scene.ts` 主要使用平面、方块、网格、点光源、紫色/青色发光和 Bloom 后处理构成场景。它能表达数据和事件，但视觉上更像科幻 HUD 背景，不能表达真实道路空间关系。当前数据适配层已经负责坐标转换、对象池和事件驱动，不在本次视觉重构中改动。

## 3. 目标视觉方向

### 3.1 环境与材质

- 默认采用浅灰天空、轻微雾气和日间方向光；保留阴天/低照度的可调入口，但不把暗色霓虹作为默认场景。
- 道路使用深灰沥青材质，路缘、人行道和建筑使用灰白/米灰色；车道线、停止线、斑马线使用高对比白/黄材质。
- 采用柔和阴影和低强度环境光，Bloom 默认关闭或降到接近不可见；移除大面积紫色透明道路面和强扫描线作为主要视觉元素。
- 资源优先使用代码生成的低多边形几何与基础材质，保证本地演示稳定；模型资源接口保留，后续可替换为 glTF 车辆和设施模型。

### 3.2 道路空间

- 建立十字路口作为默认基准场景：两条相交道路、双向车道、中心线、车道分隔线、停止线、四组斑马线、路缘和人行道。
- 在道路两侧增加低层/中层建筑体块、树木、路灯和交通信号灯，形成空间尺度参照。
- 通过 `road_layout.profile` 轻量调整公交站、货车遮挡、建筑盲区、匝道等场景，而不改变实时坐标协议。

### 3.3 交通参与者

- 自车、普通车辆、公交车、货车、面包车、自行车和行人使用可辨识的低多边形轮廓，不再用无语义的黑色方块。
- 车辆使用车身、车窗、车轮、前后灯的分层材质；行人使用头部、躯干和四肢的简化几何。
- 对象池继续按 `track_id` 动态创建、更新和销毁。实时数据只决定位置、速度、航向、类别和遮挡状态，视觉组件不反向计算事件。
- 遮挡目标使用车辆/建筑的真实空间遮挡关系表达；危险目标采用小范围轮廓、地面标记或柔和色带提示，避免覆盖整个道路的发光面。

### 3.4 镜头与交互

- 默认镜头采用参考图的斜上方路口总览，焦点落在冲突点附近，保证同时看到自车、遮挡物和目标。
- 保留 OrbitControls 的拖拽/缩放能力，但限制高度、距离和俯仰角，避免镜头穿地或飞离路口。
- 视角模式继续保留 `ego / traffic / v2i / algo`，只调整相机和信息层，不删除现有功能。

### 3.5 HUD

- 保留现有指标、事件日志、实时状态和模式切换，面板改为低透明度深灰玻璃，边框和发光显著减弱。
- 默认只保留少量青绿色作为系统状态色，风险使用黄/橙/红；不再让紫色、青色光束成为主画面。
- “LIVE / FALLBACK / TARGETS / scenario / run”信息继续显示，确保评委能看到数据驱动状态。

## 4. 实现边界

本次改动集中在：

- `frontend/src/pages/zhiluwujie/scene.ts`：场景几何、材质、灯光、相机和对象外观；
- `frontend/src/pages/zhiluwujie/ZhiluWujiePage.module.css`：HUD 背景透明度、边框、扫描线和排版对比度；
- 必要时新增同目录的纯 Three.js 工具模块，用于道路标线、车辆、树木和信号灯，避免继续扩大单文件复杂度。

以下内容保持不变：

- `sceneRealtimeAdapter`、`SceneObjectPool` 和世界坐标映射；
- Cloud API、WebSocket、SQLite 场景库和 16 个场景数据；
- 监控页、回放页和现有控制按钮的业务行为；
- 无真实车辆时的 demo/fallback 机制。

## 5. 分阶段交付

1. **第一版场景基线**：日间十字路口、道路标线、人行道、建筑、树木、信号灯、低多边形车辆/行人、稳定总览镜头。
2. **数据联动验证**：启动 GP-01、NM-01、IC-01，确认对象位置、遮挡关系和风险状态仍由实时数据驱动。
3. **风格收敛**：根据预览截图调整材质明暗、车辆比例、镜头高度和 HUD 透明度；不在没有视觉确认前加入大量装饰特效。

## 6. 验证标准

- 前端 TypeScript 构建通过；
- 现有实时适配器测试继续通过；
- 进入大屏后能看到真实道路构成，而不是纯色平面和霓虹网格；
- `GP-01` 至少同时显示自车、遮挡车辆和行人，且 `LIVE / TARGETS` 状态正确；
- 切换到无实时数据时仍保留可读的静态道路场景，不出现黑屏；
- 低性能环境下保持可交互，不引入必须联网下载的外部资源。
